## 📖 О проекте
**UrbanBlind** — это высокотехнологичное веб-приложение, созданное для помощи людям с ограниченной мобильностью, слабовидящим и незрячим пользователям. Приложение строит безопасные пешеходные маршруты по городу в обход ям, брошенных самокатов, ремонтных работ и других препятствий.

Система использует **машинное зрение (Google Gemini Vision)**, обрабатывая кадры с камеры смартфона в реальном времени, и динамически меняет веса дорожного графа (риск-зоны) на основе консенсуса пользователей!

## ✨ Ключевые возможности

* 🗺️ **Хардкорный рендеринг (Deck.gl/WebGL)**
  Отрисовка сотен тысяч дорог (GeoJSON граф Казани) со скоростью 60 FPS. Умный механизм скрытия/показа риск-зон силами видеокарты без лагов.
* 👁 **ИИ-Зрение (Краудсорсинг преград)**
  Аппаратный сканер через браузер! При обнаружении ямы или препятствия система отправляет фото ИИ. При достижении консенсуса угроза автоматически наносится на общую карту, меняя алгоритм построения маршрутов у всех пользователей.
* 🎙 **Голосовой интерфейс**
  Интеграция с Web Speech API. Достаточно продиктовать адрес назначения без помощи рук ("Поехали в Кремль").
* 📍 **Мгновенная Геолокация**
  Продвинутый алгоритм вычисления местоположения: гибридный метод с агрессивным таймаутом и молниеносным IP API fallback'ом сводит время поиска к 1-2 секундам.
* 🛣 **Граф A* (PostGIS + pgRouting)**
  Маршруты строятся на бэкенде с учетом `base_weight` (длина маршрута) и `current_risk_weight` (угрозы). Дорога через лужу будет автоматически исключена!
* 🎨 **Интерфейс «Cold Tech» Lightmode**
  Приложение оформлено в премиальных тонах Deep Blue (`#1c3044`) и Cold Slate (`#304356`), без визуального шума, с использованием микро-анимаций.

## 🛠 Технологический Стек

### Фронтенд (Frontend)
*   **Фреймворк:** React 18 / Next.js 14
*   **Карта и Визуализация:** MapLibre GL JS + Deck.GL (наложение сотен мегабайт геоданных).
*   **Стилизация:** Tailwind CSS
*   **Гео-поиск:** Photon API (Nominatim)

### Бэкенд (Backend)
*   **Dijkstra / Графы:** PostgreSQL с расширениями `PostGIS` и `pgRouting`. 
*   **Сервер:** Python + FastAPI 
*   **ORM:** SQLAlchemy (Async)
*   **AI:** `google-genai` (модель Gemini 2.0 Flash) для визуального анализа препятствий.
*   **Крон задачи:** APScheduler для медленной "очистки" города (если угроза не подтверждалась 24 часа, риск понижается).

## 🚀 Быстрый Старт

### 1. Подготовка Базы Данных
Вам потребуется Docker для поднятия специальной БД.
```bash
cd backend
docker-compose up -d
```
Сгенерируйте и загрузите дороги (например, Казань):
```bash
python seed_osm_data.py
```

### 2. Запуск Бэкенда (API)
Перейдите в папку бэкенда и запустите FastAPI:
```bash
cd backend
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
*(При желании добавьте `GEMINI_API_KEY` в файл `.env`, чтобы активировать реальный ИИ вместо mock-режима).*

### 3. Запуск Фронтенда
```bash
cd frontend
npm install
npx next dev -H 0.0.0.0 -p 3000
```
Сайт будет доступен по адресу: `http://localhost:3000`

## 🌍 Философия Дизайна
В отличие от многих "социальных" проектов, мы отказались от шаблонных кричащих цветов. Основная философия UrbanBlind — **"профессионализм и надежность"**. Мы использовали строгий градиент холодных серых и глубоких синих оттенков, добавив легкие `backdrop-blur` эффекты, чтобы приложение выглядело как инструмент премиум-класса. 

*Проект создан как подтверждение концепции краудсорсингового ИИ-города для обеспечения максимальной инклюзивности.*
