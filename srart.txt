Перед началом запуска докера нужно его открыть на компьютере
Запускаем докер:
***В теминале корневой папки прописываем***
docker-compose up -d


Запуск бэкенда:
***В корне прописываем*** 
cd backend

***а также это*** 
pip install -r requirements.txt

***и это***
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload


Запуск фронтенда:
***В корне прописываем*** 
cd frontend

***а также это*** 
npx next dev -H 0.0.0.0 -p 3000
